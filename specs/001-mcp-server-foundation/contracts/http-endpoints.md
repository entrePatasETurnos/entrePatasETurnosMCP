# Contract: HTTP Endpoints Served by the MCP Server

All endpoints are served by one Starlette app on `MCP_PORT` (default 8000). The issuer
(`MCP_PUBLIC_BASE_URL`) is the externally visible HTTPS URL.

| Method + path | Auth | Purpose | Responses |
|---|---|---|---|
| `POST/GET/DELETE /mcp` | Bearer (MCP access token) | MCP Streamable HTTP endpoint, stateless, with JSON responses. Serves the authenticated tools. | `401` + `WWW-Authenticate: Bearer resource_metadata=...` when the token is missing or invalid |
| `POST/GET/DELETE /public/mcp` | none | MCP Streamable HTTP endpoint with only `register_account`. | — |
| `GET /.well-known/oauth-authorization-server` | none | RFC 8414 metadata. Generated by the SDK. | `200` |
| `GET /.well-known/oauth-protected-resource/mcp` | none | RFC 9728 metadata for `/mcp`. Generated by the SDK. | `200` |
| `POST /register` | none | RFC 7591 dynamic client registration. Generated by the SDK. | `201`, `400` |
| `GET /authorize` | none | Starts the OAuth flow. The provider stores a pending authorization and redirects (302) to Google. | `302`, `400` |
| `GET /oauth/google/callback` | none | Google redirects here with `code` and `state`. The server exchanges the code for an `id_token`, calls `POST /v1/auth/sessions/google`, issues an MCP code, and redirects (302) to the client's `redirect_uri`. | `302`. On failure, a `302` to the client with `error=access_denied` or `server_error` plus `error_description`, carrying the API code (`account_link_required`, `account_unavailable`, `invalid_assertion`, `provider_unavailable`). Unknown or expired `state` → `400` page. |
| `POST /token` | client auth | `authorization_code` (PKCE) and `refresh_token` grants. Generated by the SDK. | `200`, `400` |
| `POST /revoke` | client auth | Revokes a token, ends the API session, and deletes all of the session's tokens. | `200` |
| `GET /healthz` | none | Liveness. | `200 {"status":"ok"}` |
| `GET /readyz` | none | Readiness: settings, Redis `PING`, and API `GET /v1/info`. | `200 {"status":"ready","checks":{...}}` or `503 {"status":"not_ready","checks":{"redis":"fail",...}}` |

## Upstream API operations used (all under `/v1`)

| Operation | Used by |
|---|---|
| `POST /v1/auth/sessions/google` | Google callback |
| `POST /v1/auth/sessions/{id}/refresh` | `SessionService.api_token()` |
| `DELETE /v1/auth/sessions/{id}` | `sign_out` and `/revoke` |
| `GET /v1/info` | `/readyz` |
| `POST /v1/users` | `register_account` |
| The `/v1/pets`, `/v1/accommodation-bookings/**` and `/v1/bath-appointments/**` operations listed in [mcp-tools.md](mcp-tools.md) | the tools |

## Google endpoints used

- `https://accounts.google.com/o/oauth2/v2/auth`: authorize, with PKCE S256 and
  `scope=openid email profile`.
- `https://oauth2.googleapis.com/token`: code exchange, using the client id and secret.
